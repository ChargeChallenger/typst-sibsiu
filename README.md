# sibsiu

Шаблон Typst для оформления студенческих работ по стандарту СибГИУ.
Требуется Typst 0.13.0 или новее.

## Использование

```typst
#import "@local/sibsiu:0.1.0": *

#show: sibsiu-work.with(
  title: "Тема работы",
  author: "Фамилия И. О.",
  group: "ИВТб-22",
)

#titlepage()
#contents()

= Введение
```

Новый проект из шаблона: `typst init @local/sibsiu:0.1.0 имя-проекта`.

## Как устроен пакет

Пакет состоит из двух частей.

**Правила на весь документ**: `sibsiu-work`. Подключаются один раз через `#show:`. Задают шрифт, абзацы, поля и нумерацию страниц, а также запоминают тему, автора и группу.

**Компоненты**: функции, которые вставляют готовую страницу там, где вызваны. Каждый вызывается тогда, когда нужен; ненужный просто не вызывается.

| Компонент     | Что делает                                                                                                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `titlepage()` | Титульный лист. Номер на нём не выводится, страница считается первой, на следующей будет номер 2. Данные берёт из `sibsiu-work`, любое можно переопределить: `titlepage(year: 2025)`. |

Если `titlepage()` не вызывать, первая страница получит номер 1.

## Как добавить свой компонент

1. Создайте файл в `src/`, например `src/appendix.typ`, с функцией, которая возвращает содержимое.
2. Если компоненту нужна страница с другими параметрами (без номера, другие поля), задайте их через `set page(...)` **внутри функции**. Правило действует только на содержимое этой функции, а после неё снова работают правила из `sibsiu-work`. Так сделан `titlepage`, и ничего включать обратно вручную не нужно.
3. Данные работы читайте из `meta` внутри `context`, как в `src/titlepage.typ`.
4. Добавьте строку `#import` в `lib.typ`: пользователю доступно только то, что перечислено там.

## Разработка и статус

План реализации требований методических указаний СибГИУ и текущий прогресс отслеживаются в [PROGRESS.md](PROGRESS.md).

Для автоматического пересчета чекбоксов и обновления шкал прогресса запустите:
```bash
python scripts/update_progress.py
```

Проверка актуальности (например, в CI):
```bash
python scripts/update_progress.py --check
```
